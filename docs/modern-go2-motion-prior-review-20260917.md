# Current Go2 motion-prior implementation review

Checked 2026-09-17. Source inspection only: no package installation, model/data download, simulator run, policy promotion, or paper reproduction. This supplements the A1/legacy AMP review in `animal-style-source-review-20260917.md`; it does not repeat that experiment proposal.

## Result

There is a current Go2/Isaac Lab AMP implementation worth studying, but the reviewed sources do **not** supply a ready-to-reproduce, licensed-data-complete recovery/stand/trot/run solution. The official Unitree and robot_lab Go2 tasks reviewed are velocity-control baselines. A separate community implementation, HimLoco-AMP-Lab, supplies actual Go2 AMP code but requires local expert trajectories and changes our policy/training interface substantially. Its source also needs checkpoint/history review before long continuation training.

Repository heads were resolved with read-only `git ls-remote`; links below pin those revisions, not floating search snippets. GitHub's anonymous API was rate-limited, so commit dates were not independently retrieved.

## What the current Go2 tasks actually provide

**Unitree:** `Unitree-Go2-Velocity` registers a manager-based PPO environment, not an AMP runner. From its enabled terms, the actor has **45** values (angular velocity 3, gravity 3, command 3, joint offsets 12, joint velocities 12, previous action 12); the critic adds linear velocity 3 and effort 12, giving **60**. Actions are **12** joint offsets at scale .25; physics .005 s / decimation 4 gives 50 Hz. Ten percent standing commands and stronger low-motion joint-position penalty explicitly address standing. Base contact and tilt terminate; this is not fallen-recovery training. The active terrain entries are flat despite the terrain variable's cobblestone name. The ±1 m/s command limit is not measured running performance. [Registration](https://github.com/unitreerobotics/unitree_rl_lab/blob/4960b84732b0c2ec593dccbfe963fda1bcd7b1e3/source/unitree_rl_lab/unitree_rl_lab/tasks/locomotion/robots/go2/__init__.py), [configuration](https://github.com/unitreerobotics/unitree_rl_lab/blob/4960b84732b0c2ec593dccbfe963fda1bcd7b1e3/source/unitree_rl_lab/unitree_rl_lab/tasks/locomotion/robots/go2/velocity_env_cfg.py).

**robot_lab:** the checked Go2 registrations are `RobotLab-Isaac-Velocity-{Flat,Rough}-Unitree-Go2-v0`, with PPO/CusRL entry points. The current README's BeyondMimic and AMP-dance examples target **G1**, not Go2; they are not quadruped datasets. [Registration](https://github.com/fan-ziqi/robot_lab/blob/500399ed75f510aeaff28705a8ce736c514dbec3/source/robot_lab/robot_lab/tasks/manager_based/locomotion/velocity/config/quadruped/unitree_go2/__init__.py), [README](https://github.com/fan-ziqi/robot_lab/blob/500399ed75f510aeaff28705a8ce736c514dbec3/README.md).

Go2 removes actor linear velocity/height scan: **45 actor / 12 action**; flat critic is **48**. Joint/action order is leg-major **FR, FL, RR, RL**, unlike our joint-type-major interface; hip action scale .125 versus .25 elsewhere. It includes stand-still, no-command foot-contact, gait and air-time-variance rewards. Wide roll/pitch resets and disabled illegal-contact termination provide recovery-related training exposure, but no checked success benchmark proves normal self-righting. [Go2 overrides](https://github.com/fan-ziqi/robot_lab/blob/500399ed75f510aeaff28705a8ce736c514dbec3/source/robot_lab/robot_lab/tasks/manager_based/locomotion/velocity/config/quadruped/unitree_go2/rough_env_cfg.py), [shared observations](https://github.com/fan-ziqi/robot_lab/blob/500399ed75f510aeaff28705a8ce736c514dbec3/source/robot_lab/robot_lab/tasks/manager_based/locomotion/velocity/velocity_env_cfg.py), [flat overrides](https://github.com/fan-ziqi/robot_lab/blob/500399ed75f510aeaff28705a8ce736c514dbec3/source/robot_lab/robot_lab/tasks/manager_based/locomotion/velocity/config/quadruped/unitree_go2/flat_env_cfg.py).

## Actual modern Go2 AMP candidate, and its blockers

HimLoco registers `Unitree-Go2-AMP` and `Unitree-Go2-AMP-Play`; its AMP environment reuses the velocity environment. It uses **45 values/frame × 6 frames = 270** policy-wrapper inputs and **12** actions, not our 48-input checkpoint architecture. The history estimator produces 3 velocity + 16 latent values; the actor MLP actually receives **64** values (current 45 + 19), not a bare 270-input MLP. [Registration](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/tasks/locomotion/robots/go2/__init__.py), [wrapper](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/rsl_rl/wrappers/himloco_vec_env_wrapper.py), [actor](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/rsl_rl/modules/amp_actor_critic.py).

- **Data is a hard reproducibility gap.** The configuration globs local `datasets/motions/trot/*.json`; the loader rejects an empty list. The README explicitly keeps expert data/checkpoints private/local and `.gitignore` excludes datasets. No reviewed public Go2 trot/run/stand expert dataset or associated data redistribution permission is supplied. Repository code permission is not permission for missing motion data. [Runner configuration](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/tasks/locomotion/agents/himloco_amp_rsl_rl_cfg.py), [publication/data description](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/README.md), [exclusions](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/.gitignore).
- **Schema is not policy input.** Motion files require 61 columns: root position/quaternion, joint positions, root-local feet, linear/angular velocity, joint velocity and foot velocity. Actual AMP state is **43**: joint positions 12 + feet 12 + body linear/angular velocity 6 + joint velocity 12 + height 1; the discriminator takes a two-state **86**-vector. Canonical AMP ordering is FL/FR/RL/RR leg blocks, resolved by names; `reorder_motion_data=False` matches that convention. The loader's 61-column comment must not be mistaken for discriminator width. [Loader](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/rsl_rl/datasets/motion_loader.py), [environment state construction](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/envs/him_manager_based_rl_env.py), [runner](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/rsl_rl/runners/amp_on_policy_runner.py).
- **Long-run restart and history need repair/testing.** Reviewed runner `save/load` persists actor/critic, PPO optimizer and estimator optimizer, but not discriminator state, AMP normalizer, replay contents or RNG; it is not a full AMP continuation checkpoint. Reviewed wrapper concatenates history at step boundaries and does not clear done rows, while `reset()` returns raw observations without refreshing its stored histories. These are concrete source omissions, not a measured failure of an executed rollout. [Runner](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/rsl_rl/runners/amp_on_policy_runner.py), [wrapper](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/rsl_rl/wrappers/himloco_vec_env_wrapper.py).
- **Standing/recovery/run are not certified.** The inspected configuration has upright resets, base-contact termination, 50 Hz control, .25 joint offsets, a velocity curriculum limited to ±2 and default playback at 1 m/s. Those commands do not establish achieved speeds, natural gait, stop quality or recovery. A trot-only motion glob gives no evidence of a stationary or fast-run style prior. Any zero-command behavior must be evaluated explicitly, not inferred from velocity tracking. [Environment](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/source/himloco_lab/tasks/locomotion/robots/go2/velocity_env_cfg.py).

## Runtime and licensing boundary

Local read-only metadata confirms Isaac Lab **2.3.2**, Isaac Sim **5.1.0.0**, Python executable **3.11.16**, RSL-RL **3.1.2**. No import or Python process was started during the ongoing evaluation pipeline. robot_lab documents a 2.3.2-compatible tag, while its checked main tracks Isaac Lab main; its setup additionally pulls `pinocchio` and `cusrl[all]`. HimLoco's README targets Sim 5.1/Python 3.11, but uses its own runner/wrapper rather than our installed RSL-RL API. Matching nominal versions therefore makes it a plausible isolated port, not verified Windows compatibility. [robot_lab compatibility](https://github.com/fan-ziqi/robot_lab/blob/500399ed75f510aeaff28705a8ce736c514dbec3/README.md), [dependencies](https://github.com/fan-ziqi/robot_lab/blob/500399ed75f510aeaff28705a8ce736c514dbec3/source/robot_lab/setup.py), [HimLoco runtime](https://github.com/JF-Li5266/HimLoco-AMP-Lab/blob/08e18142fb8e4379519be1cff54069aa311426af/README.md).

HimLoco's root LICENSE is BSD-3-Clause, but its setup metadata says Apache-2.0; retain file-level notices and resolve that inconsistency before copying/publishing. Its bundled Go2 description has a separate Unitree BSD-3-Clause notice. No motion-data license was established in this review. ## One next practical recommendation

**Make the next motion-prior milestone a small, isolated Go2 motion-data/adapter acceptance test, not another unbounded AMP training launch.** First obtain explicitly reusable reference clips covering stationary, trot, and faster motion; preserve their provenance/license and retargeting details. Validate named joint permutation, quaternion convention, 50 Hz interpolation, Go2 forward-kinematics foot locations, ground penetration and recorded speed before training. Reuse the existing physical standing/stop acceptance, and test uninterrupted episode/history handling plus checkpoint round-trip separately. Missing licensed data is an explicit stop condition for an animal-motion reproduction claim, not permission to substitute an unrelated G1 dance dataset.

Meanwhile finish the already-running matched gait experiment and continuous-flow evaluation with frozen recovery fallbacks. Neither a foreign repository's command range nor an AMP label should replace those measurements. This review alone does not justify switching the production policy, discarding existing recovery, or advertising fast running.
