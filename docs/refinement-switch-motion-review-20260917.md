# Supported-refinement 首次接管运动诊断（2026-09-17）

## 结论

在此处完整保留的 side、upside_down 各20 trial中，**40次首次自然姿态 actor 接管都出现明显的命令空间跳变**：最大单关节目标变化为0.154800–0.170410 rad（约8.87–9.76°），远大于各自接管前10步。这个结论不是任意阈值的 PASS/FAIL，也不等于真实关节瞬移或完整“平滑性”认证。

对应首个20 ms控制区间的最大真实单关节位置变化为0.004883–0.008153 rad（约0.280–0.467°）。命令目标和实际关节运动必须分别报告。4项指标在全部40个 trial的边界值均超过该 trial自身前10步的最大值；接管前已静稳，比例会因接近零的分母而很大，因此不使用倍数作通过依据。

## 范围与计算方法

只用 PowerShell 流式读取现存 JSONL，没有启动 Python、仿真或训练，没有改动模型、物理参数、阈值、历史缓冲或评估源文件。每个文件完整读取550个控制step，每step20 trial，共11,000条 trial记录；两个文件共22,000条。读取前后校验文件SHA256一致。

- 每trial边界为第一次 `refinement_active == true`；全部 `phase=postrecovery_refinement`，`strict_before_gate_steps=150`。实际边界向量与报告的首次接管step逐项相同。
- step从0计数，`policy_time_s=step×0.02` 是新action开始时间；`after` 属于此action完成后的状态（下一20 ms端点）。
- 目标变化：`max(abs(joint_target_delta_rad))`，取日志实际12维目标差，不凭 raw action 的缩放系数推算。
- 动作变化：实际12维 `issued_raw_action−previous_raw_action` 的L2与绝对值均值，使用记录的数值做双精度统计；raw action无量纲。
- 实际运动：`max(abs(after.joint_positions_rad−before.joint_positions_rad))`；这是一个已完成控制区间的关节位置差，不是目标误差、关节速度、加速度或物理子步最大运动。
- 对照为同trial边界前紧邻10个完整控制区间（0.2 s），不含接管步。所有向量检查为12维有限数，step/trial计数、窗口连续性和布尔类型均检查。
- 下表“前10步池”是20 trial×10区间的200个值，不是200个独立trial；中位数对偶数样本取中间两值均值。另列20个trial各自前10步中位数的分布，防止混淆统计单位。

## 结果与限制

现存两个报告各自记录 recovery_successes=20/20、final_valid_stands=20/20、final_refinement_holds=20/20。这些站稳/恢复结果保持原样；**不据此新增“接管自然/平滑”通过结论**。本分析未丢弃失败trial，也不扩展为未检查姿态、速度或完整连续流程的通过证明。自然姿态3746作为独立恢复策略此前 back 19/20被拒的事实亦不因本组合结果改变。

- 最大目标跳变：side trial0，step236，0.170410067 rad；upside_down trial9，step314，0.166024864 rad。
- 最大首区间真实关节位移：side trial1，step220，0.006842911 rad；upside_down trial0，step303，0.008152843 rad。它们不是对应姿态的最大目标跳变trial，不能混为同一个事件。
- 这里只有50 Hz端点数据，未检查物理子步峰值、加速度/jerk、力矩、足端滑移或接管后的完整身体轨迹；小的首区间真实位移不能证明后续视觉自然。
- 当前证据支持“下一步应专门检查/约束 actor 接管时的目标连续性”，而不是宣称恢复功能失败，或直接加入未验证的PD、插值/滤波。任何后续训练或控制改动都应保留旧恢复前缀并重新核验完整轨迹与恢复成功率。本诊断没有实施这些改动。
